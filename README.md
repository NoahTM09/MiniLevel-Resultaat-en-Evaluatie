# MiniLevel Evaluatie

Wat heb ik gebouwd? Ik heb een klein level gemaakt waarin je drie munten verzamelt en daarna naar de finish loopt.

Welk object beweegt? De blauwe capsule die beweegt met WASD. De rode balk beweegt heen en weer en de munten draaien.

Welke collider of trigger heb ik gebruikt? De munten hebben een SphereCollider als trigger. De rode balk en de finish hebben een BoxCollider als trigger.

Waar heb ik if gebruikt? Bij de finish controleert een if of je alle drie de munten hebt.

Welk extra idee heb ik toegevoegd? Als je de rode balk raakt, ga je terug naar de start. Je mag de munten die je al hebt verzameld houden.

Wat lukte goed? Na een tijdje had ik een prima idee wat niet te moeilijk was om te maken in Unity, dus dat ging goed.

Wat vond ik lastig? Ik vond het vooral lastig om mijn eigen idee toe te voegen omdat ik dat specifiek nog niet geleerd had

Wat zou ik volgende keer anders doen? Ik zou eerder kunnen beginnen.
